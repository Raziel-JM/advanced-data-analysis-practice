# Google Advanced Data Analytics – Ejercicios y Proyectos

Este repositorio contiene una recopilación de ejercicios, notebooks y proyectos desarrollados durante el programa **Google Advanced Data Analytics**, impartido a través de **Coursera** y avalado por **Google Career Certificates**.

## 🎯 Objetivo

Explorar, aplicar y reforzar conceptos clave en análisis de datos, estadística y machine learning, a través de prácticas realizadas en Python, Jupyter Notebooks y herramientas de visualización como Tableau.

## 🧠 Contenido por módulos

- **01 - Foundations of Data Science**  
  Introducción a los conceptos fundamentales, el rol del analista y el ciclo de vida de los datos.

- **02 - Get Started with Python**  
  Sintaxis básica, estructuras de datos, bucles, funciones y práctica con pandas y NumPy.

- **03 - Go Beyond the Numbers: Translate Data into Insights**  
  Exploración de datos, storytelling y análisis de negocio con datos.

- **04 - The Power of Statistics**  
  Estadística descriptiva e inferencial aplicada a conjuntos de datos reales.

- **05 - Regression Analysis**  
  Aplicación de modelos de regresión lineal y logística para detectar patrones y predicciones.

- **06 - The Nuts and Bolts of Machine Learning**  
  Introducción a machine learning supervisado y no supervisado, con scikit-learn.

- **07 - Capstone Project**  
  Proyecto integrador con análisis completo, visualización y modelo predictivo.

## 🛠️ Tecnologías utilizadas

- Python  
- Jupyter Notebooks  
- Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn  
- Tableau (visualización externa)  
- Kaggle (datasets y notebooks adicionales)
